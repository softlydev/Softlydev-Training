# Cloud & IA Accelerator — Contenu de la formation

## Mode d'emploi

Chaque module contient des leçons rédigées, un exercice pratique et des liens vers les meilleures ressources officielles et vidéos gratuites. Les niveaux : **Débutant** (aucune expérience cloud), **Intermédiaire** (bases Azure acquises), **Avancé** (prêt pour la production).

**Ce que tu vends vraiment.** Les vidéos liées sont gratuites et appartiennent à leurs auteurs : tu peux les recommander, jamais les télécharger ni les réhéberger. La valeur payante, c'est le parcours ordonné, les leçons en français, les projets guidés, les corrections et le support. Pour justifier 997 € sur la durée, remplace progressivement les liens par tes propres vidéos tournées à partir de ces leçons.

**Format de chaque leçon :** objectif · explication · ressource à regarder ou lire · exercice · vérification (« tu as réussi si… »).
