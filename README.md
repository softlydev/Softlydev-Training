## Publier la page de vente

1. Dans le dépôt : **Settings → Pages**.
2. Source : **Deploy from a branch**, branche `main`, dossier `/site`… GitHub Pages n'accepte que `/` ou `/docs` : renomme le dossier `site` en `docs` si tu veux publier directement.
3. Remplace d'abord les emplacements entre crochets : `[EMAIL SOFTLYSTACK]`, `[TÉMOIGNAGES…]`, et les liens des boutons vers ta page de paiement.

> GitHub Pages sur un dépôt privé nécessite un abonnement GitHub payant. Alternative : héberger `site/index.html` sur softlystack.com.
